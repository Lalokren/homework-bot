# Telegram-бот для сбора домашних заданий (Д/З)

Бот слушает школьный чат, запоминает все сообщения и по команде «бот дз»
 выводит аккуратный список заданий по предметам.

## Быстрый старт

### Шаг 1 — Получите токен бота

1. Откройте Telegram, найдите **@BotFather**.
2. Отправьте `/newbot`.
3. Придумайте имя бота и username ( должен заканчиваться на `bot` ).
4. Скопируйте полученный токен.

### Шаг 2 — Получите ключ GigaChat (нейросеть)

1. Зайдите на **https://developers.sber.ru**.
2. Зарегистрируйтесь (нужен номер телефона).
3. Перейдите в раздел **GigaChat** → **Профиль разработчика**.
4. Нажмите **«Выпустить ключ»** и скопируйте его.

> ⚠️ GigaChat бесплатен, но имеет лимиты:
> ~10 000 токенов на запрос, ~50 запросов в минуту.
> Для школьного чата на 30 человек это более чем достаточно.

### Шаг 3 — Настройте проект

```bash
# Склонируйте/скачайте файлы проекта в папку

# Создайте виртуальное окружение (рекомендуется)
python -m venv venv

# Активируйте его:
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# Установите зависимости
pip install -r requirements.txt

# Создайте .env из шаблона
cp .env.example .env
```

Откройте файл `.env` и впишите:

| Переменная        | Что вписать                                                                 |
|-------------------|-----------------------------------------------------------------------------|
| `BOT_TOKEN`       | токен бота от @BotFather                                                    |
| `GIGACHAT_API_KEY`| ключ из профиля разработчика Сбера                                          |
| `GIGACHAT_SCOPE`  | `GIGACHAT_API_PERS` (личный) или `GIGACHAT_API_B2B` (корпоративный ключ)    |
| `GIGACHAT_MODEL`  | модель: `GigaChat-2`, `GigaChat-2-Pro`, `GigaChat-3-Pro`                    |
| `ALLOWED_CHAT_IDS`| ID чатов через запятую (или оставьте пустым)                                |

> ⚠️ **Про `GIGACHAT_SCOPE`.** Если тип ключа и значение не совпадают —
> GigaChat вернёт ошибку `scope from db not fully includes consumed scope`.
> Ключ личный → `GIGACHAT_API_PERS`, корпоративный (B2B) → `GIGACHAT_API_B2B`.

> ⚠️ **Про бесплатные токены.** Бесплатный пакет (~1 000 000 токенов) даёт
> **только личный ключ (PERS)**. Корпоративный ключ (B2B) работает по
> предоплате и без неё отвечает ошибкой **402 «Payment Required»**.
> Если ваш ключ B2B и токенов нет — выпустите в кабинете Сбера личный ключ
> и поменяйте `GIGACHAT_SCOPE=GIGACHAT_API_PERS`.

### Шаг 4 — Запустите

```bash
python bot.py
```

### Шаг 5 — Добавьте бота в классный чат

1. Добавьте бота в группу. Он пришлёт приветствие с ID чата и подсказкой.
2. **Обязательно** дайте боту права **администратора** (закладка «Управление
   чатом» → «Добавить администраторов»). Без этого Telegram в режиме
   приватности просто не присылает боту обычные сообщения группы.
   Альтернатива: @BotFather → `/setprivacy` → Disable.
3. В чате напишите «бот тест» — бот проверит связь с нейросетью.
4. Напишите «бот дз» — получите Д/З за сегодня.

## Как работает

- Бот автоматически сохраняет **все сообщения** из чата в базу SQLite.
- Когда кто-то пишет «бот дз», он берёт все сообщения за день,
  отправляет их в нейросеть **GigaChat** и получает структурированный
  список заданий по предметам.
- Нейросеть учитывает контекст: если одно сообщение отвечает на предыдущее
  (например, «номера 12–15» → «по геометрии»), она связывает их.
- Сообщения с фото/документами получают ссылку 📎 в столбике Д/З.

## Команды

| Команда                  | Что делает                              |
|--------------------------|-----------------------------------------|
| `бот дз`                 | Д/З за сегодня                          |
| `бот дз вчера`           | Д/З за вчера                            |
| `бот дз позавчера`       | Д/З за позавчера                        |
| `бот дз 12 сентября`     | Д/З за 12 сентября                      |
| `бот дз 01.05`           | Д/З за 1 мая                            |
| `бот тест`               | Проверить связь с нейросетью            |
| `помощь`                 | Справка по командам                     |

## Если бот не реагирует в группе

Телеgram в «режиме приватности» (включён по умолчанию) отдаёт боту только
команды с `/`, ответы на его сообщения и упоминания. Обычные сообщения вроде
«бот дз» бот просто не получает. Исправляется одним из двух способов:

1. **Выдайте боту права администратора** в настройках группы.
2. Или в **@BotFather**: `/setprivacy` → выберите бота → **Disable**.

После этого добавьте бота в группу заново или подождите пару минут —
и проверьте командой «бот тест».

## Ограничения и альтернативы

| Сервис     | Бесплатный лимит                       | Ограничение                                  |
|------------|----------------------------------------|----------------------------------------------|
| GigaChat   | ~50 запросов/мин, ~10 000 токенов/запрос | Без голосового, медленнее чем GPT            |
| YandexGPT  | 10 000 токенов/мес бесплатно           | Нужен аккаунт Яндекса и SMS-подтверждение    |

Если GigaChat не устраивает — замените `ai_service.py` на YandexGPT API:
ключ выдаётся в [Dialogs API](https://yandex.cloud/ru/services/yandexgpt).

## Структура файлов

```
bot.py              ← Главный файл: обработчики, команды, запуск
database.py         ← Работа с SQLite (сохранение / чтение сообщений)
ai_service.py       ← Интерфейс к GigaChat (определение Д/З)
.env.example        ← Шаблон переменных окружения
requirements.txt    ← Python-зависимости
```
